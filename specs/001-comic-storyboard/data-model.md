# 資料模型：漫畫分鏡與腳本草稿管理工具

## 資料範圍與政策

- 僅保存漫畫創作內容，不建立使用者帳號、不保存學生身分資料、不同步至伺服器。
- 資料保存在同一瀏覽器設定檔，直到創作者刪除或清除瀏覽器資料。
- 成人教育者已核准此保存方式；使用者介面仍須提示共用裝置的存取風險。
- 瀏覽器可能拒絕或清除本機資料；失敗時保留編輯畫面中的內容並明確提示。

## 實體

### 本機草稿集合（LocalDraftStore）

| 欄位 | 型別 | 說明與驗證 |
|---|---|---|
| `schemaVersion` | 正整數 | 本機資料格式版本；載入時檢查是否支援。 |
| `drafts` | 漫畫草稿陣列 | 本機保存的漫畫草稿集合。 |

### 漫畫草稿（ComicDraft）

| 欄位 | 型別 | 說明與驗證 |
|---|---|---|
| `id` | 字串 | 草稿識別碼；在本機草稿集合中唯一，不包含個人資料。 |
| `title` | 字串 | 漫畫名稱；去除前後空白後不得為空。 |
| `createdAt` | ISO 8601 日期時間 | 建立時間。 |
| `updatedAt` | ISO 8601 日期時間 | 最近一次成功保存時間。 |
| `chapters` | 章節陣列 | 依 `position` 由小至大排列；可為空。 |

### 章節（Chapter）

| 欄位 | 型別 | 說明與驗證 |
|---|---|---|
| `id` | 字串 | 章節識別碼；在所屬草稿中唯一。 |
| `title` | 字串 | 章節名稱；建立流程要求輸入；允許不同章節使用相同名稱。 |
| `position` | 正整數 | 草稿內顯示順序；不得與同一草稿中其他章節的順序重複。 |
| `panels` | 分鏡陣列 | 依 `position` 由小至大排列；可為空。 |

### 分鏡（Panel）

| 欄位 | 型別 | 說明與驗證 |
|---|---|---|
| `id` | 字串 | 分鏡識別碼；在所屬章節中唯一。 |
| `position` | 正整數 | 章節內顯示順序；不得與同一章節中其他分鏡的順序重複。 |
| `visualDescription` | 字串 | 可選的畫面描述；保留使用者輸入的文字及換行。 |
| `dialogue` | 字串 | 可選的分鏡對話；保留使用者輸入的文字及換行。 |

### 匯出大綱（OutlineExport）

匯出大綱是由漫畫草稿即時產生的結果，不另行持久保存。內容包含漫畫名稱、依序排列的章節與分鏡，以及所有已填寫的畫面描述和對話。

## 關係

- 一份漫畫草稿包含零個或多個章節。
- 一個章節屬於一份漫畫草稿，並包含零個或多個分鏡。
- 一個分鏡只屬於一個章節。
- 匯出大綱由一份漫畫草稿及其巢狀章節、分鏡資料衍生。

## 狀態與保存規則

1. **編輯中**：使用者可修改草稿；畫面保留尚未成功保存的內容。
2. **已保存**：保存成功後更新 `updatedAt`，草稿可在同一瀏覽器設定檔重新開啟。
3. **保存失敗**：顯示明確錯誤並留在編輯畫面；不得清除目前輸入或顯示成功狀態。
4. **刪除確認中**：使用者取消時回到原草稿；確認後移除該草稿。
5. **匯出**：不改變草稿狀態；無章節時顯示無法匯出的原因。

## 儲存格式與相容性

- 使用單一版本化本機資料集合保存草稿；資料中不包含使用者帳號、姓名或學校名稱。
- 讀取失敗或遇到不支援的資料版本時，必須保留原始資料，不得靜默覆寫；顯示明確錯誤並提供使用者匯出或求助指引。
- 刪除草稿只移除所選草稿，不影響其他草稿。
