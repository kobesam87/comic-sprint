# 使用者介面合約：漫畫分鏡與腳本草稿管理工具

## 範圍

本功能沒有伺服器 API 或外部服務介面。此文件定義學生可操作的網頁流程與匯出結果。

## 草稿清單

- 提供建立草稿、開啟草稿及刪除草稿的操作。
- 建立草稿須輸入漫畫名稱；不得要求姓名、電子郵件、學校名稱或帳號。
- 刪除前須顯示確認步驟；取消後草稿不變，確認後該草稿不再出現。
- 不提供登入、多人協作、雲端同步或公開分享功能。
- 在保存草稿前，以適齡文字提醒使用者：同一瀏覽器設定檔的其他使用者可能看見草稿，清除瀏覽器資料可能使草稿遺失。

## 漫畫編輯器

- 顯示漫畫名稱、章節清單、目前章節中的分鏡及保存狀態。
- 支援新增章節、新增分鏡，以及編輯各分鏡的畫面描述與對話。
- 章節與分鏡以草稿中的順序呈現；不同章節即使同名也須可區分。
- 提供明確的保存操作；保存失敗時保留目前畫面內容並顯示原因，不顯示成功狀態。
- 重新開啟已保存草稿時，內容及順序須與保存前一致。

## 匯出大綱

- 草稿至少包含一個章節時，提供匯出操作。
- 匯出為 UTF-8 純文字 `.txt`，內容順序如下：

  1. 漫畫名稱
  2. 章節名稱（按章節順序）
  3. 分鏡序號（按章節內順序）
  4. 已填寫的畫面描述及對話

- 未填欄位不輸出佔位文字；已輸入的換行及文字不得遺漏。
- 無章節時說明無法匯出，且不產生空白檔案。
- 匯出失敗時顯示明確錯誤，不顯示成功狀態。
- 匯出由使用者自行保存或交給成人教育者；工具不建立公開連結或代為分享。

## 可及性與適齡互動

- 所有操作均須可用鍵盤完成，焦點位置清楚可見。
- 輸入欄位、按鈕及錯誤訊息須有清楚標籤，文字使用國小四至六年級學生可理解的台灣繁體中文。
- UX/UI 設計與驗收參考 WCAG 2.2 指引；不以本合約宣稱法律合規。
