# 四格漫畫任務｜我的漫畫冒險

這是一個給國小四至六年級學生使用的漫畫分鏡與腳本草稿工具。學生可以建立漫畫、安排章節與分鏡、編輯畫面描述和對話，並匯出文字大綱。

## 開始使用

需要 Node.js 22.12 以上版本及 npm。

```sh
npm ci
npm run dev
```

依終端機顯示的本機網址開啟工具。

## 草稿保存與隱私

- 草稿只保存在目前瀏覽器設定檔，不建立帳號、不上傳或跨裝置同步。
- 共用裝置的其他使用者可能看見草稿；清除瀏覽資料也可能刪除草稿。
- 在漫畫清單選擇「刪除這份漫畫」，確認後即可刪除該草稿。
- 匯出的大綱是純文字檔，由使用者自行保存；請勿把含個人資料的內容放入漫畫草稿。

## 匯出大綱

開啟漫畫後，選擇「匯出漫畫大綱」即可下載 UTF-8 `.txt` 檔。沒有章節時，工具會說明無法匯出。

## 開發檢查

```sh
npm run test:unit
npm run test:e2e
npm run build
```

端對端測試使用 Playwright；首次執行前，依 Playwright 官方指引安裝 Chromium、Firefox 及 WebKit 測試瀏覽器。
